# Interactive3DWorld-Udacity

An Interactive3DWorld adventure game developed in Unity 
where the player explores a terrain environment, navigates 
obstacles, and collects items using the Ellen character 
from the 3D Game Kit.

## 🎯 Game Objective
Navigate the dangerous terrain as Ellen, step on the 
pressure pad to activate the moving platform, cross 
the acid pool, and collect all 3 crystals to win!

## 🎮 Controls
| Key | Action |
|-----|--------|
| W A S D | Move Ellen |
| Mouse | Look around |
| Spacebar | Jump |
| Left Mouse Button | Attack |
| Escape | Pause Menu |

## ⚠️ Enemies & Hazards
- **Acid Pool** — Do not fall in! Use the moving platform to cross
- **Chomper Enemies** — Attack with left mouse button to defeat them

## 🎒 Helpful Items
- **Health Boxes** — Restore Ellen's health
- **Checkpoints** — Save your progress

## ⚠️ WebGL Browser Notes
- Click the game screen first to activate keyboard controls
- The Quit button is disabled in WebGL due to browser 
  security restrictions — use Restart Level instead
- Best experience on **Chrome** or **Firefox**
- For full experience including working Quit button, 
  use the Windows build from Google Drive
